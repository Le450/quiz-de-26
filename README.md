# MON D.E · Quiz de révision du Diplôme d'État infirmier

Application de quiz gratuite pour réviser le Diplôme d'État infirmier (INFAS, Côte d'Ivoire), faite par des étudiants pour des étudiants.

**Ouvrir l'appli : https://le450.github.io/quiz-de-26/**

## Ce que tu peux faire

- Réviser les sujets D.E blanc 2026 et les anciens D.E, par antenne et par matière, avec la correction après chaque question.
- Accéder aux journées de Révision nationale 2025 (J1 à J10).
- Faire un quiz personnalisé ou un examen chronométré.
- Suivre ton plan de révision jusqu'au D.E.
- Revoir tes erreurs avec la révision éclair.
- Marquer des questions, réviser les fiches formules, gagner des badges.
- Sauvegarder ta progression pour changer de téléphone.

Pas de compte à créer. Ta progression reste sur ton téléphone.

## Installer l'appli

- **Android (Chrome)** : menu à trois points, puis « Installer l'application ».
- **iPhone (Safari)** : bouton Partager, puis « Sur l'écran d'accueil ».

Ouvre le site dans Chrome ou Safari, pas dans le navigateur de WhatsApp.

## Une erreur dans une question ?

Utilise le bouton de signalement sous la question. Les corrections sont déterminées sans corrigé officiel : en cas de doute, vérifie avec ton cours.

## Projet

Projet d'entraide, gratuit et sans but commercial.
